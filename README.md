# RT1064 麦克纳姆轮全向底盘控制系统

基于 NXP **i.MX RT1064**（Cortex-M7，600 MHz）与逐飞开源库实现的四轮麦克纳姆轮全向底盘。包含麦轮运动学解算、里程计定位、位置-角度-速度三环串级控制、任务状态机，以及 VOFA+ 在线调参与 TFT 屏幕调试菜单。

底盘可在平面内做**全向移动**：前后、左右横移、斜向移动、原地旋转，并支持"给定坐标点自主移动 + 定点转向"，位置容差 5 cm。

---

## 功能特性

**运动控制**

- 四轮麦轮**逆运动学解算**（O 型布局）：车身三轴速度 `(vx, vy, ω)` → 四个轮子的目标编码器脉冲数
- **里程计正解**：四轮编码器 → 车身速度 → 经陀螺仪航向角旋转到世界坐标系 → 积分得到位姿 `(x, y, yaw)`
- **三环串级控制**：位置环 → 角度环 → 速度环，内环速度环始终运行
- **角度环分段策略**：小角度用标准 PID（带积分分离，避免稳态抖动）；大角度切非线性转向 PID（动态 Kp，误差越大增益越高，加速收敛）
- **速度环**：增量式 PID + 误差一阶低通滤波 + 平滑加减速 + 静摩擦死区补偿 + 方向突变补偿，四轮独立计算
- 四路正交编码器测速（QTIMER 正交解码模式，读取即清零，天然得到"每周期脉冲数"）

**任务与调试**

- **任务状态机**：待命 → 移动到目标点 → 到位 → 等待识别 → 返航
- 6 种运行模式可切换（纯速度环 / 纯角度环 / 位姿环 / 整赛题流程 / 停止）
- **VOFA+** 经无线转串口输出波形，实时观察目标值、实际值、PID 输出
- 无线串口支持文本指令在线改参数（`process_command_line`）
- TFT180 屏幕三级菜单，可脱离上位机现场改模式、看数据

## 硬件平台

| 项目     | 型号 / 参数                                                  |
| -------- | ------------------------------------------------------------ |
| 主控     | NXP i.MX RT1064（Cortex-M7 @600 MHz，4 MB Flash / 1 MB RAM） |
| 电机驱动 | DRV8701 双路 H 桥（驱动板为本项目自绘，见 `pcb/`）           |
| 电机     | 直流减速电机 ×4，减速比 70:14                                |
| 编码器   | 增量式正交编码器 ×4，1024 线（4 倍频）                       |
| 姿态     | IMU660RA 六轴陀螺仪（提供航向角）                            |
| 显示     | TFT180（128×160）                                            |
| 调试     | 无线转串口模块（VOFA+ 上位机）                               |

**主要引脚分配**

| 功能       | 引脚                                                         |
| ---------- | ------------------------------------------------------------ |
| 编码器 1~4 | QTIMER 正交解码通道（4 路，具体编号见 `hardware/encoder.h`） |
| 电机 PWM   | PWM_CH1 ~ CH4                                                |
| 电机方向   | 对应 DIR 引脚（见 `hardware/Motor.c` 的 `Motor_Match` 表）   |
| 串口 1     | TX:B12 / RX:B13，115200                                      |
| 串口 2     | TX:B18 / RX:B19，115200                                      |
| 无线转串口 | TX:D16 / RX:D17                                              |
| TFT180     | SCK:B0 / CS:B3 / MOSI:B1                                     |
| IMU660RA   | SCK:C23 / MOSI:C22 / MISO:C21 / CS:C20                       |

> 完整的引脚分配与避坑说明见 `project/RT1064智能车推荐引脚分配.txt`（C4~C15 为芯片配置引脚，尽量不用作输入）。

## 控制架构

```
                    ┌──────────────────────────────────────────┐
   目标位姿 (x,y,yaw) │              位置环 + 角度环               │
   ──────────────────▶│  Alg_Position_Control()                  │
                    │    ├─ 角度环：分段 PID → 目标角速度 ω       │
                    │    └─ 位置环：世界坐标误差 → 车体系误差      │
                    │              → 目标速度 (vx, vy)          │
                    └───────────────────┬──────────────────────┘
                                        │
                                        ▼
                    ┌──────────────────────────────────────────┐
                    │      逆运动学 Kinematics_Inverse_Calc()   │
                    │   V_lf = vy + vx − ω(L+W)                │
                    │   V_rf = vy − vx + ω(L+W)                │
                    │   V_lb = vy − vx − ω(L+W)                │
                    │   V_rb = vy + vx + ω(L+W)                │
                    │        → 4 × 目标编码器脉冲/周期            │
                    └───────────────────┬──────────────────────┘
                                        ▼
                    ┌──────────────────────────────────────────┐
                    │        速度环 ×4  VelocityPID_Calculate()  │
                    │  增量式 PID + 低通滤波 + 死区补偿 + 限幅     │
                    └───────────────────┬──────────────────────┘
                                        ▼
                              PWM 占空比 → DRV8701 → 电机
                                        │
                     ┌──────────────────┘
                     ▼
        编码器正交解码 → Odometry_Update() 里程计正解
            四轮速度 → 车身速度 → 航向旋转 → 位姿积分
```

**中断分配**

| 中断    | 周期  | 任务                                           |
| ------- | ----- | ---------------------------------------------- |
| PIT_CH0 | 3 ms  | 读取四轮编码器、里程计更新、速度滤波、三环控制 |
| PIT_CH1 | 5 ms  | IMU660RA 陀螺仪解算                            |
| PIT_CH2 | 15 ms | 按键扫描                                       |
| PIT_CH3 | 10 ms | 计时                                           |

主循环（`main.c`）只做三件事：刷新 UI 菜单、读无线串口指令、发送 VOFA 数据。控制算法全部在 3 ms 定时中断中完成，保证控制周期严格等间隔。

## 关键参数

| 参数           | 取值                             | 说明                     |
| -------------- | -------------------------------- | ------------------------ |
| 轮径           | 63 mm                            | `CAR_WHEEL_DIAMETER`     |
| 轴距 L         | 198.16 mm                        | 前后轮中心距             |
| 轮距 W         | 180.32 mm                        | 左右轮中心距             |
| 几何系数       | L/2 + W/2                        | 逆解中的旋转力臂         |
| 电机减速比     | 70:14                            | `CAR_GEAR_RATIO`         |
| 编码器侧减速比 | 70:30                            | `GEAR_RATIO_ENCODER`     |
| 编码器线数     | 1024                             | 4 倍频后                 |
| 脉冲/米        | 理论 12266.9，**实测标定 12000** | 推车 1 m 数脉冲标定      |
| 控制周期       | 3 ms                             | `pit0_dt = 0.003f`       |
| 位置容差       | X/Y 各 5 cm                      | `POSITION_TOLERANCE_X/Y` |

> **为什么理论值和实测值差 2%**：理论值按几何参数与减速比算得，实测值包含轮子打滑、轮径磨损、装配误差的综合影响。用实测值做里程计，1 m 距离误差从 2 cm 压到 1 cm 内——**这一项不标定，位置环永远调不稳**。

## 编译与烧录

- **工具链**：Keil MDK 5（工程文件 `shiki_code/project/mdk/rt1064.uvprojx`）；IAR 工程备用（`project/iar/rt1064.eww`）
- **依赖**：逐飞 RT1064 开源库已包含在 `shiki_code/libraries/`，无需额外下载
- **烧录**：J-Link（`project/mdk/JLinkSettings.ini`）
- **注意**：工程路径移动或重命名后，必须执行 `Project → Clean` 再全编译，否则会因绝对路径残留导致链接失败（`main.c` 顶部注释亦有说明）

首次上电自检顺序：屏幕点亮并显示 logo → 陀螺仪零漂校准（**此时车必须静止**）→ 电机 PWM 归零 → 编码器就绪 → PIT 中断启动。

## 调试方法

**1. VOFA+ 波形观测**

无线转串口输出四路目标值/实际值/PID 输出，VOFA+ 选 FireWater 或 JustFloat 协议即可看到曲线。整定顺序：先速度环（单轮空载），再角度环（原地转），最后位置环（给坐标点）。

**2. 无线指令在线改参**

串口发文本指令可直接改 Kp/Ki/Kd 与目标速度，无需重新烧录（`vofa.c` 的 `process_command_line`）。

**3. 屏幕菜单**

三级菜单可切换 6 种模式：

| 模式                       | 用途                             |
| -------------------------- | -------------------------------- |
| `MODE_DEBUG_NORMAL_VEL`    | 纯速度环，配合 VOFA 整定速度 PID |
| `MODE_ANGLE_PID_TEST`      | 纯角度环，原地转向               |
| `MODE_POSE_PID_TEST`       | 位姿环，给定 (x, y, yaw)         |
| `MODE_DEBUG_CAM_OFFSET`    | 相机误差直接进位置环（预留）     |
| `MODE_DEBUG_SERIAL_TARGET` | 上位机下发目标点（预留）         |
| `MODE_RACE_FULL`           | 完整赛题流程（状态机）           |

## 已知限制与后续计划

诚实记录，便于后续接手：

- **`arrive_point()` / `arrive_destination()` 尚未实现**：状态机框架与模式分发已搭好，到点后的分类、抓取流程待补
- **上位机串口协议（`Upper_Connect.c`）仅预留接口**：目前靠无线串口 + VOFA+ 调参，未做正式二进制协议
- **左后轮静摩擦偏大**，死区补偿在 `PID_Control.c` 中按轮号硬编码（`i == 2` 分支），换电机需重新标定
- **位置环参数与场地相关**：地面材质变化（瓷砖/地毯）会影响打滑，需要重新标定脉冲/米
- 逆解符号与电机接线强相关，`MCar_Control.c` 顶部有 `WHEEL_DIR_LF/RF/LB/RB` 四个宏，接线改动后在此处翻转
